# MeshCore-RS Companion для Heltec Mesh Node T096

Подключение к приложению MeshCore по BLE или USB. PIN для BLE отображается на TFT. Встроенный GNSS включается на странице GPS. Параметры радио при первом запуске унаследованы от nRF52840 Companion в MeshCore-RS. Мощность SX1262 по умолчанию 9 дБм до усилителя KCT8103L.

### Сборка

Из корня репозитория:

```powershell
cd firmware/models/t096
cargo build --locked --release --bin companion
python ../../../tools/uf2/elf2uf2.py target/thumbv7em-none-eabihf/release/companion meshcore-rs-heltec-t096-companion.uf2 --bin heltec-t096-companion.bin
```

На Windows при ошибке длинного пути в сборке вложенного установщика задайте `CARGO_TARGET_DIR` на короткий каталог. ELF будет в `$CARGO_TARGET_DIR/thumbv7em-none-eabihf/release/companion`.

### Установка

1. Подключите антенну LoRa и USB-кабель. Дважды быстро нажмите RST.
2. Если на диске загрузчика есть `CURRENT.UF2`, сохраните его для отката. Если важны прежняя идентичность и настройки, экспортируйте их в старой прошивке. Companion создаёт собственную идентичность при первой установке.
3. Скопируйте `meshcore-rs-heltec-t096-companion.uf2` на диск загрузчика. Дождитесь автоматической перезагрузки.
4. Откройте MeshCore, выберите устройство `MeshCore-…` и введите PIN с экрана T096. Задайте параметры LoRa своей сети.

Первая установка версии с OTA выполняется через UF2. У неё та же область данных Companion, что у первой Rust-сборки. Для восстановления по USB после прерванного OTA используйте UF2 с поддержкой OTA, чтобы устройство могло прочитать временную копию данных.

### Обновления по LoRa

Нужен напрямую слышимый репитер MeshCore-RS с поддержкой платы `heltec-t096`, `set fw.serve on` и доступом к серверу с подписанной дельтой `.mcfd` для роли `companion`. Дельта должна быть построена от точного `.bin` текущей сборки. Для локальной сборки сохраните `.bin`, полученный вместе с UF2. CI включает T096 в общую сборку подписанных выпусков и дельт.

В CLI Companion задайте отпечаток ключа, которым подписан выпуск, затем включите режим.

```text
set fw.root <отпечаток-публичного-ключа>
set fw.auto install
fw
```

На чистой установке автообновление выключено. `set fw.auto download` скачивает дельту и ждёт `fw install`. `set fw.source auto` выбирает репитер автоматически. `fw check` запрашивает обновление сразу. Для dev-выпусков доступно `set fw.channel dev`.

Настройки, идентичность, каналы, BLE-пары и контакты временно хранятся отдельно, пока область Companion занята дельтой. При трёх неудачных пробных загрузках установщик возвращает предыдущую прошивку. Если для сохранения данных или обратной дельты не хватает места, установка отменяется. Если загрузчик запомнил CRC прежнего образа через serial DFU, установите сборку через UF2.

Сборка рассчитана на штатный загрузчик с S140 6.1.1. Программный порог штатной прошивки 3,3 В при низком заряде пока не перенесён. Сборка и OTA проверены вне платы.

Распиновка по [схеме Heltec V0.2](https://resource.heltec.cn/download/Mesh_Node_T096/Schematic/Mesh_Node_T096_V0.2.pdf) и [варианту MeshCore](https://github.com/meshcore-dev/MeshCore/tree/75b04ef06def54b348400cb1b138afb6749ffd4f/variants/heltec_t096).
