esp32c6-bootloader.bin SHA-256 bfe7a8a539d06d8da984d42ce02bf985f97d363f03b1513adce8277da11532ee

Each image sets the board's flash size in the bootloader header and updates its SHA-256.
The partition table at 0x8000 comes from the matching board CSV in tools/desktop-flasher.
The app image comes from the selected .mcfw file at installation time.
