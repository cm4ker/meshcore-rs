# ota-app для MeshCore-RS

Выберите способ подключения, нажмите «Проверить устройство» и сверьте модель и сборку. В разделе «Из GitHub» подходящая прошивка выделена отдельно. Можно выбрать файл с диска. Нажмите «Обновить прошивку» и дождитесь результата в журнале.

- **USB.** Выберите последовательный порт. Для .uf2 переведите nRF52 в USB-загрузчик и укажите диск платы. «Прошить через USB» устанавливает полный образ на поддерживаемую ESP с работающей MeshCore-RS и совместимой двухслотовой разметкой. «Новая нода со сбросом» дополнительно удаляет прежний ключ и пользовательские данные после подтверждения.
- **Обновление по Bluetooth.** Найдите устройство, открыв на нём окно подключения. Файл .bin применяется только к плате, принимающей полные неподписанные образы приложения.
- **Wi-Fi / TCP.** Введите адрес платы в локальной сети. Порт по умолчанию 5000. Используйте подписанный .mcfw или дельту .mcfd для установленной сборки.
- **Загрузчик nRF52 (UF2).** Переведите плату в BLE OTA. Найдите загрузчик и выберите .uf2 для модели и роли. Этот режим рассчитан на совместимый Nordic Legacy DFU с S140 6.1.1. Из .uf2 также можно сохранить пакет DFU ZIP.

| Система | Файл релиза |
| --- | --- |
| Windows x86 / x64 | `ota-app-1.3-Windows-x86-x64.exe` |
| macOS на Apple Silicon | `ota-app-1.3-macOS-Apple-Silicon.zip` |
| Linux на ПК x86-64 | `ota-app-1.3-Linux-PC-x86_64.tar.gz` |
| Linux на Raspberry Pi и других ARM64 | `ota-app-1.3-Linux-Raspberry-Pi-ARM64.tar.gz` |
| Raspberry Pi OS 32-bit (ARMv7/ARMv8) | `ota-app-1.3-Linux-Raspberry-Pi-ARMv7-32bit.tar.gz` |

На macOS распакуйте приложение. На Linux распакуйте архив и запустите ./MeshCore в графическом сеансе. Для USB нужны права пользователя на последовательный порт, для Bluetooth — работающий адаптер и системная служба Bluetooth.

Сборка macOS и Linux: Python 3.11 с Tk, затем bash build.sh ARCH в этой папке. Для Linux нужны Tk, Xvfb, xauth и binutils. Для Windows: 32-битный Python 3.11, затем windows/build.ps1 из этой папки. Графический клиент использует OTA meshcore-rs, esptool и pyserial. Иконка взята с nw.ommesh.ru.
