# ota-app для MeshCore-RS

Выберите способ подключения, нажмите «Проверить устройство» и сверьте модель и сборку. В разделе «Из GitHub» подходящая прошивка выделена отдельно. Можно выбрать файл с диска. Нажмите «Обновить прошивку» и дождитесь результата в журнале.

## Офлайн-библиотека

Перед выездом откройте «Офлайн» → «Скачать набор…». Выберите выпуск, модель и роль или оставьте «Все платы» и «Обе роли». Набор содержит опубликованные для них `.mcfw`, `.mcfd` и `.uf2`. Одиночные загрузки из раздела «Из GitHub» тоже сохраняются в библиотеке.

На месте подключите устройство и нажмите «Проверить устройство». Откройте «Офлайн» и выберите сохранённую прошивку. Для дельты `.mcfd` приложение сверяет исходную сборку и контрольную сумму. Для UF2 выберите режим загрузчика nRF52 или его USB-диск. Список файлов и выбор прошивки работают без интернета. Если загрузка оборвалась, повторный запуск докачает недостающие файлы.

Фильтр «Только дельты .mcfd» показывает сохранённые дельты. Подпись `r188 → r194` означает обновление со сборки r188 до r194.

Способ подключения и сведения о плате находятся в карточке «Подключение». Выбор файла и запуск установки находятся в карточке «Прошивка». В нижней панели виден текущий статус. Кнопка «Развернуть» открывает журнал целиком.

Поставьте в журнале флажок «Сохранять журнал в Загрузки». По завершении операции приложение сохранит её ход и ошибки в отдельный файл `ota-app-*.txt` в системной папке загрузок.

- **USB.** Выберите последовательный порт. Для .uf2 переведите nRF52 в USB-загрузчик и укажите диск платы. «Прошить через USB» устанавливает полный образ на поддерживаемую ESP с работающей MeshCore-RS и совместимой двухслотовой разметкой. «Новая нода со сбросом» дополнительно удаляет прежний ключ и пользовательские данные после подтверждения.
- **Первая установка MeshCore-RS из `.mcfw`.** Выберите файл для точной модели ESP и нажмите «Новая нода со сбросом». Приложение покажет модель и роль из файла. После подтверждения оно автоматически войдёт в загрузчик, очистит всю флеш-память и запишет загрузчик, таблицу разделов и приложение. Для обновления действующей ноды с сохранением настроек используйте «Обновить прошивку».
- **Первая установка по USB на ESP32-S3 или ESP32-C6.** Выберите полный `*-merged.bin` для точной модели платы и нажмите «Прошить через USB». Приложение само войдёт в загрузчик и запишет образ, включая загрузчик и таблицу разделов. Запись перезапишет данные в области образа. «Новая нода со сбросом» для `*-merged.bin` очищает всю флеш-память после подтверждения.
- **Heltec V3 со штатной разметкой MeshCore.** Откройте обычный `Heltec_v3_*.bin` с flasher.meshcore.io и нажмите «Прошить через USB». Прошивка записывается в другой слот с сохранением разделов данных. Для смены разметки используйте `*-merged.bin` для своей платы.
- **Обновление по Bluetooth.** Найдите устройство, открыв на нём окно подключения. Файл .bin применяется только к плате, принимающей полные неподписанные образы приложения.
- **Wi-Fi / TCP.** Введите адрес платы в локальной сети. Порт по умолчанию 5000. Используйте подписанный .mcfw или дельту .mcfd для установленной сборки.
- **Загрузчик nRF52 (UF2).** Переведите плату в BLE OTA. Найдите загрузчик и выберите .uf2 для модели и роли. Этот режим рассчитан на совместимый Nordic Legacy DFU с S140 6.1.1. Из .uf2 также можно сохранить пакет DFU ZIP.

На macOS распакуйте приложение. На Linux распакуйте архив и запустите ./MeshCore в графическом сеансе. Для USB нужны права пользователя на последовательный порт, для Bluetooth — работающий адаптер и системная служба Bluetooth.

Сборка macOS и Linux: Python 3.11 с Tk, затем bash build.sh ARCH в этой папке. Для Linux нужны Tk, Xvfb, xauth и binutils. Для Windows: 32-битный Python 3.11, затем windows/build.ps1 из этой папки. Графический клиент использует OTA meshcore-rs, esptool и pyserial. Иконка взята с nw.ommesh.ru.
